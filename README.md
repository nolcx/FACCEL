# FACCEL

**FACCEL** es una herramienta web que permite **extraer, analizar y procesar archivos XML** de sistemas de facturación de Hacienda.  
Con FACCEL puedes **identificar, separar y sumar impuestos** de forma automática, facilitando la gestión contable y fiscal.

## Funciones principales

- 📂 Carga y lectura de archivos XML de facturas electrónicas.
- 🧠 Extracción automática de datos clave (emisor, receptor, montos, impuestos, etc.).
- ➕ Cálculo de **sumatorias de impuestos** (IVA, IEPS, etc.).
- 💻 Interfaz web intuitiva y fácil de usar.

## Ideal para

Contadores, PYMEs y desarrolladores que necesitan **automatizar el análisis de facturas electrónicas** y optimizar la gestión de impuestos.
